SUPERGO 1.8.0 for Windows
=========================
Build:  double-click build.bat   (needs Python 3.10+ and internet, once)
Result: dist\SUPERGO.exe  (single file, same icon as the Linux app)
Needs:  Microsoft Edge WebView2 Runtime (already on Windows 11 and most Windows 10).
VPN:    put xray.exe (github.com/XTLS/Xray-core/releases) next to SUPERGO.exe.
Run:    SUPERGO.exe [--profile NAME] [--private] [URL...]
Data:   %APPDATA%\SUPERGO\<profile>
